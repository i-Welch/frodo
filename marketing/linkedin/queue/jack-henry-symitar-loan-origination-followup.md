"We integrate with Jack Henry" is the start of a vendor conversation, not the end.

Jack Henry has two main cores with two different APIs. SilverLake connects through jXchange, which now has a REST version alongside SOAP. Symitar connects through SymXchange. A vendor live on one may not be live on the other.

The partner program changed too. In July 2025, Jack Henry replaced its Vendor Integration Program with the Fintech Integration Network, now 850+ fintechs. Membership means API access and an integration review, not a live integration on your core.

Three questions before the demo:

Which core and which API?
How many institutions on my core are live today?
What does it write back: the booked loan, the customer record, the documents?
